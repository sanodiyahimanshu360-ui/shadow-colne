Inside your .gitignore file, add one rule per line using these patterns:Ignore a specific file:secret.txtIgnore an entire folder and its contents:node_modules/ or logs/Ignore all files with a specific extension:*.log (ignores all .log files everywhere)Ignore files in a specific folder only:/debug/*.txt (ignores .txt files inside the root debug folder, but not in sub-folders)Add comments:Lines starting with # are ignored by Git.
